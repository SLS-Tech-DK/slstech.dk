# slstech.dk

Kildekoden til [slstech.dk](https://slstech.dk) — SLS Techs hjemmeside.

Statisk multi-side site i håndskrevet HTML, CSS og JavaScript (alt inline, intet framework):

- **index** — forside
- **ydelser.html** — services og priser
- **om-sls-tech.html** — folkene bag
- **lab.html** — SLS Techs udviklingsværksted (Kniven, afgang, Own din diabetes)
- **referencer.html** — leverede opgaver
- **privatliv.html** — privatlivspolitik

Open Graph-tags, mobil og desktop, Google Fonts. Hostet på Simply.

Lagt i GitHub som single source of truth, så siden kan versioneres og rulles tilbage — en del af SLS Tech-byggestandarden.

## Note
Kildekode-snapshot af den live side. Ingen nøgler eller persondata.
